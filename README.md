# Soundboxd

A "Letterboxd, but for music" — a platform to log, rate, and review albums, inspired by the Letterboxd experience (which does this for movies).

## About

The core idea is to create a space where users can:

- Search for albums and artists (via Spotify API integration)
- Mark albums as listened and rate them
- Write free-text reviews
- Build custom lists (e.g. "Top 10 of 2025")
- Follow other users and see what they're listening to/rating

The project is in its early development stage, starting with the static frontend before integrating the backend and the Spotify API.

## Technologies

**Frontend (in progress):**
- HTML5
- CSS3

**Planned:**
- Spotify API integration, for album/artist search and metadata
- PostgreSQL, as the database for users, reviews, ratings, and lists
- Backend (language/framework still to be decided)

## Status

Project in early development. For now, the home page is built with fixed (placeholder) data just to validate the layout — the next step is connecting real data via the Spotify API and deciding on the backend.
